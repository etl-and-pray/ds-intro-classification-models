# Практическая работа 22.9: Обучение моделей классификации (Дерево решений и Случайный лес)

## Описание проекта
Практическая работа направлена на освоение базовых и продвинутых методов машинного обучения для задач классификации. В ходе работы проведено сравнение моделей дерева решений и случайного леса, а также выполнен подбор гиперпараметров для оптимизации качества.

## Цели работы
* Потренироваться в обучении моделей **дерева решений (Decision Tree)**.
* Потренироваться в обучении моделей **случайного леса (Random Forest)**.
* Освоить оценку качества моделей с помощью метрик **Accuracy** и **Confusion Matrix** (матрицы ошибок).
* Научиться повышать качество моделей с помощью **тюнинга параметров** (гиперпараметров).
* Провести программный анализ важности признаков (**Feature Importance**) и автоматизировать фильтрацию данных.

## Основные этапы выполнения
1. **Загрузка и первичный анализ данных:** знакомство с датасетом, проверка пропусков и типов данных.
2. **Базовая модель (Дерево решений):** обучение классификатора и замер исходных метрик качества.
3. **Базовая модель (Случайный лес):** обучение ансамбля деревьев и сравнение результатов с деревом решений.
4. **Оптимизация и тюнинг:** увеличение точности модели случайного леса на тестовых данных за счет подбора гиперпараметров.
5. **Анализ признаков:** программный анализ влияния фичей на предсказания модели и автоматическое удаление малозначимых/лишних колонок на основе `feature_importance` и типов данных.
