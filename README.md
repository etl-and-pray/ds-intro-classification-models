# Классификация ценовой категории автомобилей: Decision Tree и Random Forest

Учебный проект по классификации объявлений о продаже автомобилей на три ценовые категории (`low`, `medium`, `high`). Сравниваются дерево решений и случайный лес, затем модель тюнингуется до точности выше 0,76 на тестовой выборке. В конце проверяется, насколько подготовка признаков влияет на качество.

## Результаты

| Модель | Accuracy на тесте |
|---|---|
| Decision Tree (все признаки) | 0,6705 |
| Decision Tree (без признаков с нулевой важностью) | 0,6726 |
| Random Forest (базовый, `random_state=50`) | 0,7419 |
| **Random Forest (после тюнинга)** | **0,7606** |
| Random Forest на сырых данных (только числовые колонки) | 0,6403 |

**Выводы**
- Случайный лес даёт на 7 п.п. больше точности, чем одиночное дерево (0,7419 против 0,6726).
- Удаление 1096 признаков с нулевой важностью (осталось 364) почти не меняет качество дерева (+0,2 п.п.), но заметно упрощает модель.
- Подготовка признаков (One-Hot Encoding, масштабирование, признаки из текста объявления) даёт около +12 п.п. по сравнению с сырыми числовыми колонками (0,7606 против 0,6403).
- Сложнее всего классифицируется категория `medium`: модель чаще всего путает её с соседними категориями.
- На сырых данных в топ-3 по важности попали `odometer` (0,27), `year` (0,23) и `id` (0,17). Попадание `id` в топ — повод насторожиться: это идентификатор, а не свойство автомобиля, и такой вклад скорее шум, чем полезный сигнал.

## Что сделано

1. **Подготовка данных.** Из подготовленного датасета объявлений (9 619 строк) убраны `price` и `odometer/price_std`, чтобы цена не попала в признаки. Разбиение train/test 70/30, `random_state=42`.
2. **Дерево решений.** Обучение `DecisionTreeClassifier`, замер Accuracy и матрицы ошибок. Признаки с нулевой `feature_importances_` удаляются кодом, а не вручную, после чего модель обучается заново.
3. **Случайный лес.** `RandomForestClassifier` на сокращённых выборках, сравнение с деревом по Accuracy и confusion matrix.
4. **Тюнинг.** Подбор параметров леса вручную: `n_estimators=5000`, `max_features='log2'`, `class_weight='balanced_subsample'`, остальные по умолчанию. Результат: 0,7606.
5. **Анализ влияния признаков.** Загрузка исходного (необработанного) датасета, удаление `price` и всех строковых колонок (кодом, через `select_dtypes`), обучение лучшей модели, сравнение качества и поиск трёх самых важных признаков.

## Стек

Python · Pandas · Scikit-learn (`DecisionTreeClassifier`, `RandomForestClassifier`, `train_test_split`, `accuracy_score`, `confusion_matrix`) · Jupyter / Google Colab

## Ограничения

- Параметры леса подбирались вручную с оглядкой на тестовую выборку, поэтому 0,7606 может быть немного оптимистичной оценкой. Для честной оценки нужны кросс-валидация и отдельная валидационная выборка.
- Тюнинг не систематический (без `GridSearchCV` / `RandomizedSearchCV`), и 5000 деревьев — это дорого по времени при небольшом приросте точности.
- Единственная метрика — Accuracy. Для более полной картины стоит добавить precision, recall и F1 по классам.
